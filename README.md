# 🛒 WIThSHOP - 쇼핑몰 이커머스 서비스
https://wit-h.shop

**WIThSHOP**은 누구나 상품을 등록하고 구매할 수 있는 오픈마켓 형태의 쇼핑몰 플랫폼입니다.  
Google OAuth2 기반 로그인, JWT 인증, 상품 등록/주문/리뷰 등 **쇼핑몰의 핵심 기능**을 직접 구현한 프로젝트입니다.

> 기본적인 백엔드 CRUD 구현을 완료했으며, React 기반 프론트엔드 연결과 AWS를 이용한 배포를 개발할 예정입니다.
> 
> AI 챗봇 기능도 추가 개발할 예정입니다.
---

##  주요 기능
- Google OAuth2 및 로컬 로그인
- JWT 기반 사용자 인증 및 권한 분리 (고객 / 관리자)
- 상품 등록, 조회, 장바구니, 주문 및 결제
- 리뷰 및 대댓글, 좋아요, 신고 기능
- 관리자 페이지 (회원 관리, 게시물 관리 등)

---

## 🛠️ 기술 스택

| 구분         | 사용 기술                                   |
|--------------|---------------------------------------------|
| **Back-end** | Java, Spring Boot, Spring Security, JPA     |
| **Database** | MariaDB, Redis                              |
| **Infra**    | AWS EC2, AWS S3                             |
| **Front-end**| React
